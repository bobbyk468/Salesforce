## Step 2: Convert Image 1 — OWD Hierarchy (1 minute)

### Upload:
1. Click "Choose a file"
2. Navigate to: `/Users/brahmajikatragadda/Downloads/salesforce-certifications/assets/week-1-images/`
3. Select: `1-owd-hierarchy.svg`
4. Click "Open"

### Convert Settings:
1. Look for "Output format" dropdown (on the right side)
2. Select: **PNG**
3. Under "PNG options", set:
   - Width: 1200
   - Height: 1500

1. Wait ~10 seconds for conversion
2. Click "Download" button (green)
3. File saves as: `1-owd-hierarchy.png`

## Troubleshooting

**If CloudConvert doesn't work:**
- Try **https://convertio.co** (alternative)
- Or use **Figma.com** (free, more professional)
- Or ask me to request Gemini to convert them

**If dimensions are wrong:**
- CloudConvert has dimension controls
- Image 1: 1200x1500 (portrait)
- Images 2-4: 1200x630 (landscape)

**If file won't upload:**
- Make sure file is `.svg` (not `.SVG`)
- Try dragging the file directly to CloudConvert
- Clear browser cache and retry
