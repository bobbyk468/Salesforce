## How to use in GSC

1. Open [Google Search Console](https://search.google.com/search-console) → **URL Inspection** (top).
2. Paste one URL from above (use **non-www** only).
3. Press Enter → click **Request indexing**.
4. Repeat for each URL (or submit the sitemap once: `https://trailblazeprep.com/sitemap.xml` and request indexing for the sitemap URL to ask Google to crawl all).

**Note:** Submitting the sitemap URL in GSC (Sitemaps) already asks Google to crawl these URLs; “Request indexing” per URL prioritizes that URL. Use the list above for manual “Request indexing” on specific pages.
