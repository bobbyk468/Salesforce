## INSTRUCTIONS FOR USE

1. **Copy this file weekly** - Create a new version each week (e.g., `X-PREMIUM-CAMPAIGN-TRACKER-WEEK-1.csv`)

2. **Fill in actual data daily** - Don't wait until end of week. Update impressions/clicks daily from X Analytics

3. **Calculate metrics automatically** - Use formulas:
   - CTR = Clicks / Impressions × 100
   - CPE = Budget Spent / Total Engagements
   - CPC = Budget Spent / Total Clicks
   - Engagement Rate = Total Engagements / Impressions × 100

4. **Review weekly** - Every Friday, analyze performance and adjust next week's strategy

5. **Identify patterns** - Which variants outperform? Which time slots? Which audiences?

6. **Optimize constantly** - If CTR < 2%, kill the tweet. If CTR > 5%, scale budget.
