## RED FLAGS & PAUSE CONDITIONS

### PAUSE Campaign If:
- [ ] CTR drops below 2% and stays there for 24+ hours
- [ ] CPC exceeds $3.00 (too expensive)
- [ ] Audience responding with negative/spam comments
- [ ] Landing page has high bounce rate (>80%)

### KILL Campaign If:
- [ ] CTR below 1% after 200+ impressions
- [ ] No clicks after $50 spent
- [ ] Brand reputation concerns

### SCALE Campaign If:
- [ ] CTR exceeds 5% consistently
- [ ] CPC below $1.00
- [ ] High-quality engagement (substantive replies)
- [ ] Landing page conversion rate >2%
