## Video 2 — "The Salesforce security model in 60 seconds"
**Type:** Face to camera OR whiteboard with simple drawing
**Length:** 60 seconds exactly
**Hook:** "The Salesforce security model explained in 60 seconds. This answers 5–8 questions on the Admin exam."

**Script:**
> "Four layers. That's it.
>
> Layer one: OWD — Org-Wide Defaults. This is the floor. It sets the MOST RESTRICTIVE access everyone gets by default. Usually Private or Public Read Only.
>
> Layer two: Role Hierarchy. This opens access UP. Your manager can see your records. Their manager can see everything below them.
>
> Layer three: Profiles. This is the ceiling. What objects can this user even access? What can they read vs edit vs delete?
>
> Layer four: Permission Sets. These are exceptions. They ADD permissions on top of a Profile. They never remove them.
>
> The exam question is almost always: 'A user needs to see X but not Y.' Your job is to identify which layer is responsible and what setting to change.
>
> OWD, Roles, Profiles, Permission Sets. In that order. Every time."
