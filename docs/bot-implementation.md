# Trailblaze Prep — Certification Bot Implementation

## Overview

A RAG (Retrieval-Augmented Generation) chatbot that answers Salesforce certification questions using content from trailblazeprep.com and official Salesforce Trailhead pages. Designed to be free at runtime with no per-request API billing for the retrieval layer.

---

## Architecture

```
User question
     │
     ▼
[ChatBot.tsx] — React client component, floating widget
     │  POST /api/chat  { message, history }
     ▼
[/api/chat/route.ts] — Next.js App Router API route
     │
     ├── BM25 keyword search (in-process, zero external calls)
     │   └── Reads bot-data/knowledge-base.json (loaded once, cached)
     │
     └── Groq API  (free tier — Llama 3.3 70B, 14,400 req/day)
              │  streaming SSE response
              ▼
[ChatBot.tsx] — streams tokens to UI
```

### Why this design is "free at runtime"

| Layer | Cost |
|---|---|
| BM25 retrieval | Zero — pure in-process math, no API |
| LLM inference | Zero — Groq free tier, no credit card required |
| Hosting | Zero — Vercel free tier handles the API route |
| Knowledge base | Zero — static JSON committed to repo |

## Training

### Run training

```bash
npm run bot:train
```

This will:
1. Fetch `https://www.trailblazeprep.com/sitemap.xml` and scrape all content pages
2. Scrape ~50 Trailhead credential overview pages (all major roles)
3. Scrape the Trailhead Academy offerings page (JS SPA — uses puppeteer)
4. Chunk all text into ~350-word segments
5. Write `bot-data/knowledge-base.json`

### Training sources

**trailblazeprep.com** — all pages discovered via sitemap.xml:
- 87 cert pages (exam format, key concepts, practice questions, FAQ)
- Exam tips pages, comparison pages, certification path pages
- Certification cost, list, and commercial pages

**Trailhead credential overview pages** — ~50 official Salesforce credential pages:
- All Admin, Developer, Consultant, Architect, Designer, AI, Tableau, MuleSoft credentials
- URL pattern: `https://trailhead.salesforce.com/en/credentials/{slug}overview/`

**Trailhead Academy** — certification offerings catalog:
- `https://trailheadacademy.salesforce.com/all-offerings#f-assetType=Certification`

### Retraining cadence

Retrain whenever:
- A new cert page is added to trailblazeprep.com
- Salesforce releases a new certification
- Exam content changes (Spring/Summer/Winter release cycles)
- After major content updates to existing pages

After retraining, commit `bot-data/knowledge-base.json` to git and push — Vercel will pick it up on the next deploy.

## Retrieval — BM25

BM25 (Best Match 25) is a classical keyword retrieval algorithm — the same backbone used by Elasticsearch and Lucene.

### How it works

For each user query:
1. Tokenize query → remove stopwords → lowercase
2. Score every chunk: `IDF × TF` where:
   - IDF = inverse document frequency (rare terms score higher)
   - TF = term frequency normalized by chunk length
3. Return top-5 chunks by score as context for the LLM

Parameters: `k1 = 1.5`, `b = 0.75` (standard BM25 defaults)

### Index lifecycle

The BM25 index is built **once** on first API request (loading + tokenizing the JSON), then cached in the Node.js module scope for the lifetime of the serverless function instance. Cold-start cost: ~50–200ms depending on knowledge base size.

### Tradeoffs vs embeddings

| | BM25 | Embeddings |
|---|---|---|
| External API at query time | None | Requires embedding API call |
| Query cost | Zero | $0.0001–0.001 per query |
| Semantic understanding | Keyword match only | Understands synonyms, paraphrase |
| Setup | Self-contained | Requires vector DB |
| Quality for domain-specific terms | Excellent (cert names, exam terms) | Good |

For Salesforce certification queries — which use precise terminology like "ADM-201", "Platform Developer I", "passing score" — BM25 performs comparably to embeddings.

## LLM — Groq (free tier)

**Model**: `llama-3.3-70b-versatile`
**API**: `https://api.groq.com/openai/v1/chat/completions`
**Auth**: `GROQ_API_KEY` environment variable

### Free tier limits (as of 2026)

- 14,400 requests/day on Llama 3.3 70B
- 30 requests/minute
- No credit card required

Sign up at https://console.groq.com

### Prompt design

- System prompt constrains the bot to Salesforce certifications only
- Context (top-5 BM25 chunks) injected into each user message
- Last 6 conversation turns included for multi-turn coherence
- `max_tokens: 350`, `temperature: 0.2` — concise, factual responses
- Response streamed via SSE → client renders tokens progressively

### Rate limiting (server-side)

20 requests per IP per 60 seconds. Prevents a single user from exhausting the Groq daily quota.

## Frontend — ChatBot component

- `position: fixed`, bottom-right — outside the main layout grid
- Mounted via `dynamic(() => import('@/components/ChatBot'), { ssr: false })` — no SSR hydration cost
- Salesforce blue (`#0176D3`) consistent with site theme
- Suggested starter questions shown until first user message
- Animated "thinking" dots while streaming
- `AbortController` cancels in-flight requests if user closes the panel
- Mobile responsive: max-width capped at `calc(100vw - 2rem)`

## Vercel deployment

`next.config.js` includes:

```js
outputFileTracingIncludes: {
  '/api/chat': ['./bot-data/**/*'],
},
```

This tells Next.js's output file tracing to include the `bot-data/` directory in the `/api/chat` serverless function bundle. Without this, Vercel would not bundle the JSON file and the API route would fail silently.

### Environment variables (set in Vercel dashboard)

| Variable | Value |
|---|---|
| `GROQ_API_KEY` | Get free key from https://console.groq.com |

## Graceful degradation

If the knowledge base is empty (before first training run):
- BM25 returns no chunks
- LLM responds from its general Salesforce training knowledge
- Response quality is lower but the bot still functions

If `GROQ_API_KEY` is missing:
- API returns HTTP 503 with a clear error message
- Widget shows the error message to the user

## Future improvements

- **Hybrid retrieval**: BM25 + embeddings re-ranker for better semantic matching
- **Incremental training**: Only re-scrape pages that have changed (use ETags / Last-Modified)
- **Analytics**: Log queries to identify gaps in the knowledge base
- **Feedback loop**: Thumbs up/down on answers to flag low-quality responses
- **Streaming abort**: Show "Stop generating" button while response streams
