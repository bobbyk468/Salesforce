# Salesforce Platform Administrator: a six-week study plan

Preparing for the Salesforce Certified Platform Administrator exam is easier when you pair each topic with a small task in a practice org. Adjust the schedule to your experience and check the current Salesforce exam guide before booking.

1. **Configuration and Setup:** create a user; compare profiles, permission sets, roles, and sharing.
2. **Object Manager and Lightning App Builder:** build an object, create fields and relationships, and configure a Lightning page.
3. **Data and Analytics Management:** import sample data, build reports, and check dashboard visibility.
4. **Automation:** compare record-triggered and screen flows, then configure an approval process.
5. **Sales, Service, Productivity, and Agentforce:** practise lead conversion and case routing; review collaboration tools and Agent Builder basics.
6. **Review:** take a timed practice test, examine the explanations, and revisit weak areas in a practice org.

A useful habit for scenario questions is to name the required result and constraint before choosing a feature. For a record-change automation, for example, consider whether the task updates the triggering record or needs to act on related records. For human sign-off, consider an approval process.
